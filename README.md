# 🏏 IPL Score Prediction using Deep Learning

A Deep Learning-based machine learning project that predicts the final score of an IPL cricket innings using historical match data and match statistics.

## 📌 Project Overview

Predicting the final score of a T20 innings is a challenging task due to the dynamic nature of cricket. This project leverages Deep Learning techniques to analyze match conditions and predict the final score based on the current state of the game.

The model is trained on historical IPL match data and uses features such as batting team, bowling team, current score, wickets lost, overs completed, and recent run rate.
